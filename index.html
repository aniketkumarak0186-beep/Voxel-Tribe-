Create a complete, polished, interactive VR marketplace prototype called **“Campus Reuse”** for **on-campus selling and buying of old, unused, or pre-owned student products**. The goal is to create a simple virtual campus marketplace where college students can discover, inspect, list, and purchase second-hand items from other students on the same campus. ## Core Concept Students often have products they no longer use, such as: * Textbooks and notes * Calculators * Laptops and accessories * Headphones and speakers * Cycles * Sports equipment * Furniture * Bags * Hostel essentials * Electronics * Stationery * Other useful pre-owned products The application should make it easy for students to **reuse products, save money, and sell unused items within their campus community**. ## Technical Constraints You MUST follow all of these requirements: 1. Use **A-Frame WebVR/WebXR**. 2. Produce **exactly one HTML file** named: `index.html` 3. Put **all HTML, CSS, and JavaScript inside the same `index.html` file**. 4. Do not create additional files. 5. Do not require a build system, npm, React, Vue, Angular, or backend. 6. Use CDN-based libraries when necessary. 7. The experience must support **Meta Quest 3S controllers** through WebXR. 8. The experience must also work on a normal desktop/laptop. 9. Desktop users must be able to interact using a **keyboard and mouse**. 10. The page should run by opening `index.html` in a suitable browser/server environment. 11. Keep the implementation self-contained and easy to understand. ## Platform Support ### Meta Quest 3S Provide an immersive VR experience with: * Meta Quest 3S controller support * Controller-based pointing * Ray interaction * Trigger/select interaction * Teleport or comfortable movement where appropriate * VR UI panels * Clearly visible interactive buttons * Comfortable scale and spacing * Readable text in VR * Avoid unnecessary rapid movement The application should work with standard WebXR-compatible A-Frame interactions. ### Desktop Provide a desktop fallback with: * Mouse interaction * Keyboard movement * WASD movement * Arrow-key movement where practical * Mouse-look or equivalent camera control * Clickable UI elements * Ability to enter and exit VR Display a clear **“Enter VR”** button when WebXR is available. ## Main Experience Create a visually appealing **virtual college marketplace**.
